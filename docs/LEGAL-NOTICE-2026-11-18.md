## 0.1 一页速览

- 这是**非官方**的 DSH 客户端插件：在左侧栏账号信息下方显示汀岚小桌宠，提供本地互动、文本聊天、Advisers 简报读取与提醒创建。与 DeepSeek 官方无关联、未获授权或背书；由 PerryLink（个人项目）维护，不是 DeepSeek 官方产品。
- 汀岚是 **AI 角色，不是真人**。聊天回复由**你在 DSH 中配置的模型**生成（默认跟随 DSH 默认模型选择），**输入文本会发送给对应模型供应商**。
- 语音朗读使用**浏览器/系统语音合成**（不一定在本地，音色与联网行为由浏览器/操作系统决定）；语音输入使用**浏览器语音识别**，**音频可能发送给浏览器厂商**。插件本身不接收、不保存音频。
- **不提供角色扮演（roleplay）、情感陪伴、虚拟亲密关系**；**不提供专业建议**（医疗/法律/金融/心理等）。
- **Advisers 简报**只读你本机 `~/.advisers/pet-brief.json`，投影后仅在界面显示，不上传、不写入日志、不进入模型/语音；可能含客户/同事信息，**共享屏幕前请关闭**。
- **无账号、无遥测、无服务端日志、无 API Key**。本机仅在浏览器 `localStorage` 保存设置与 TTS/ASR 同意记录；可清除。
- 许可：代码 **PolyForm Noncommercial 1.0.0**（**不是 OSI 开源**），美术 **CC BY-NC-SA 4.0**；仅限非商业用途，商业使用须书面许可。
- 已知缺口（不隐藏）：无首启告知、无 About/危机资源页、简报未完整实现 `displayPolicy: private` 与过期校验、无「清除本机数据」按钮、README 部分能力表述不准确（见 §11）。

## 1. 定位与能力（事实）

### 1.1 已实现（2026-11-18 代码）

| 能力 | 事实 | 数据去向 |
|---|---|---|
| 本地互动 | 摸摸/给纸片/折一下/左右看；帧动画、气泡；仅本地 UI 状态 | 本机，不出网 |
| 文本聊天 | `op:"chat"` → DSH Host `ctx.llm.stream`；provider/model 来自 DSH 默认模型或插件 Config；模型不可用时返回 503，**不伪造回复** | 输入文本 → DSH Host → 用户配置的模型供应商 |
| Advisers 简报 | `op:"brief"` 只读 `~/.advisers/pet-brief.json`（≤128 KiB），只投影计数 + 最多 3 条 title/commitments；`displayPolicy: none` 拒绝 | 本机读取；返回给插件界面；不上传 |
| 提醒 | `op:"task"`/`op:"task-delete"` → DSH `schedule` 服务 | 本机/DSH 宿主 |
| 语音朗读 | 浏览器 `speechSynthesis`（设置中开启并单独同意后） | 浏览器/操作系统语音；是否联网取决于平台/音色 |
| 语音输入 | 浏览器 `SpeechRecognition`（点击麦克风 + 单独同意后） | **可能发送给浏览器厂商**；插件不接收音频文件 |
| 本地回显 | `op:"echo"` | 仅本地，不出网 |

### 1.2 未实现 / 不提供（不得对外宣称已具备）

- 角色扮演（roleplay）、情感陪伴、虚拟恋人/伴侣/亲属、长期关系；
- 专业建议（医疗/法律/金融/心理）、诊断/治疗/法律结论/投资建议；
- 自建人格/自定义系统提示/自定义声音的上传入口（当前系统提示由插件固定，用户不可在 UI 修改）；
- 云 TTS/云 ASR 的插件内置 Key（语音走浏览器/系统；不调用 DeepSeek TTS/ASR）；
- 多用户、远程访问、客户会话、人工接管、客服/对外服务模式；
- 数据导出、审计、账号体系、遥测、服务端日志。

> 说明：插件**有真实 LLM 聊天**，所以不能写「不提供自由 LLM 对话」；准确的表述是「不提供角色扮演/情感陪伴/虚拟亲密关系，聊天为普通 AI 回复」。

## 3. 数据流与保留

### 3.1 插件/宿主侧

| 数据 | 路径 | 接收方 | 保留 |
|---|---|---|---|
| 聊天输入 | `POST /api/famling/bridge`（同源、owner-only、≤16 KB、≤2000 字符）→ `op:chat` → `ctx.llm.stream` | DSH Host → 模型供应商 | 插件不落盘；供应商/宿主留存以各自条款为准 |
| 聊天回复 | 模型流式返回 → 气泡显示 | 仅界面 | 插件不落盘 |
| Advisers 简报 | 本地只读 `~/.advisers/pet-brief.json` → 投影返回 | 仅界面 | 不落盘；建议用户按简报 TTL 使用（插件当前未强制校验 `expiresAt`） |
| 提醒 | `op:task` → DSH `schedule` | DSH Host | 以 DSH 为准 |
| 本地回显 | `op:echo` | 仅界面 | 不保留 |

### 3.2 浏览器侧

| 数据 | 位置 | 说明 |
|---|---|---|
| 设置 | `localStorage['dsh-famling/settings']` | 语音朗读/帧动画/气泡开关；清除浏览器站点数据即删除 |
| TTS/ASR 同意 | `localStorage['dsh-famling/consent/v1']` | `{tts, asr}` 布尔；无版本/哈希/审计 |
| 语音识别音频 | 浏览器 → 浏览器厂商 | 插件不接收音频文件；点击麦克风后才启动；可关闭 |
| 语音合成 | 浏览器/系统语音 | 文本交给 `speechSynthesis`；是否联网取决于平台/音色 |
| 会话/页面数据 | DSH 宿主/浏览器 | 以 DSH 与浏览器条款为准 |

### 3.3 不收集/不发送（插件自身）

- 无账号、无遥测、无崩溃上报、无服务端日志、无 API Key、无 Cookie 写入；
- 不读取 DSH 会话历史、不读取其他用户数据、不读取 Advisers 数据库；
- 不把 Advisers 简报发给模型/语音、不写入文件、不导出。

| 配置 | 位置 | 风险/注意 |

## 6. AI 披露与标识

**当前展示**：输入面板与设置面板各有一句「AI 声明：角色与语音为 AI 生成/合成，不是真人；本插件不提供自由 LLM 角色扮演或情感陪伴」。

**必须如实告知的事实**：角色与语音为 AI 生成/合成；聊天回复为 AI 生成且可能出错；不是真人；不是 DeepSeek 官方产品（PerryLink 为维护者）；不提供专业建议/角色扮演/情感陪伴。

**已知缺口（不得宣称已具备）**：无首启告知；无 About/法律页；无每条回复/每次播放的 AI 标签；无语音播放常驻标签/首播提示；无导出标识；无版本化同意记录。公开发布前建议至少补：首启 1 屏告知 + 设置内法律入口 + TTS/ASR 独立同意升级 + 播放时可见标签。

## 7. 隐私与个人信息

1. **插件不设账号、不上传分析数据**；DSH 宿主/模型供应商可能处理你的输入，适用其条款。
2. **不要输入**：密码/密钥、身份证/银行卡、他人隐私、客户数据、未成年人信息、医疗/法律敏感信息——除非你确认有权且符合你所在组织的规则。
3. **Advisers 简报**可能含客户/同事个人信息；仅在私人环境查看；共享屏幕/录屏前关闭；不要复制到聊天/语音/文档。
4. **共享电脑**：使用后清除浏览器站点数据（设置 + 同意）并退出 DSH；插件不提供单独的「清除本机数据」按钮（缺口）。
5. **删除**：清除 `dsh-famling/settings`、`dsh-famling/consent/v1` 即删除插件本机数据；DSH 会话/日志按 DSH 方式删除；Advisers 数据按 Advisers 方式删除。
6. **跨境**：若你的 DSH 模型/浏览器语音服务在境外，相关数据可能出境；请自行确认供应商披露与合法性基础。
