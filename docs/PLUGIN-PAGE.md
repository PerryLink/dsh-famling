# Famling · 汀岚（DSH 插件页说明）

**是什么**：本插件在 DeepSeek Harness 左侧栏左下角、账号信息下方显示一个小型像素桌宠入口——可在汀岚 / 布偶猫（白底蓝重点长毛）/ 金毛之间切换。默认只渲染角色本身，角色以外没有常驻按钮；它是 DSH 里的轻量技术演示入口，不是独立桌宠应用，也不是情感陪伴产品。

**怎么用**：右键角色（或按 Shift+F10 / ContextMenu）打开分级菜单：聊两句… / 互动 ▸ / 内容与角色… / 设置… / 更多 ▸；点击角色头部 / 身体 / 尾巴分别触发对应互动与随机回话。设置弹窗集中所有可调项（语音、气泡、低打扰、缩放、内容与角色、数据与边界），也可以在设置里开启一个可选的「显示菜单按钮」。

**低打扰**：默认开启安静时段（22:00–08:00 内不产生自动气泡与随机微动作，点击、菜单与聊天回复仍照常）、动画偏好跟随系统的「减少动态」、支持暂时隐藏；「一起工作」专注模式 25 / 50 分钟只在本机内存计时，结束只提示一次。语音 TTS/ASR 需要单独同意，可随时撤回。除同源 Host bridge 外不联网、无遥测。

**兼容与自检**：`package.json` 的 `engines.dsh` 声明支持的 DSH 版本区间，`dsh.compatibility.dshReleases` 维护最新三版兼容矩阵。离线自检一条命令：`node scripts/verify-dsh.mjs`（支持 `--json`、`--dsh-version`，退出码 0/1/2），检查清单见 [DSH-COMPATIBILITY.md](DSH-COMPATIBILITY.md)。Host 缺少 llm / schedule 能力时聊天与提醒如实降级、不伪造回复。
