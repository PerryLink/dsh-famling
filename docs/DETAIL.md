# Famling · 汀岚

在 DSH 左侧栏左下角、账号信息下方显示一个小型 famling 桌宠入口。

- 显示汀岚像素头像与状态点。
- 点击展开本地小面板：摸摸 / 给纸片 / 折一下；每次操作切换表情帧并做弹跳/缩放动画，仅本地 UI 状态，不调用模型、不上传数据。
- 不宣传 roleplay；不替代独立 famling 应用。

限制：这是 DSH 客户端插件，不是完整桌宠；完整可执行版在 `PerryLink/famling`。

## 最终界面结构

- 左侧 72px 人物。
- 右侧竖排：输入 / 互动 / 设置。
- 输入：右侧文本框 + 语音输入按钮；DSH/Advisers Host 桥接预留。
- 互动：自由选择动作；点击人物随机动作。
- 设置：语音、帧动画、气泡开关。
- 气泡虚线，显示桌宠台词/猫狗心里话；不遮挡人物。
